# Basketball illustration

`basketball.gif` is the previously generated two-panel trajectories-only
illustration for five-player NBA retrieval. It shows the selected query from a
Dallas-at-Clippers game and the returned Clippers-at-Lakers play.
It contains 32 frames of court-coordinate animation and no broadcast footage.

In the pinned full corpus, the displayed example corresponds to held-out query
327, the seed-2301 blocking evaluation, and an exact distance of about 7.89 feet.
Matching colors show player correspondence. The ball is context only.

The GIF is an illustration selected from completed results; it is not a random
sample and is not used to tune parameters or calculate recall.
See `docs/BASKETBALL.md` for regeneration and authorized local video composition.
